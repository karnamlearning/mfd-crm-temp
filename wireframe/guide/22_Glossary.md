# 22 · Glossary: simple meanings

Words used on the screens and in these guides, in plain English.

## Business and MF terms
| Term | Meaning |
|---|---|
| **MFD** | Mutual Fund Distributor: a person or firm that helps investors buy and sell mutual funds and earns commission from AMCs. |
| **MF Box Back Office** | AdvisorKhoj's software that MFDs already use for transactions, records, portfolio statements and MIS. The CRM reads its data. |
| **Tenant** | One MFD firm using the CRM. Each firm's data is private to that firm. |
| **RM** | Relationship Manager: the staff member who looks after a set of clients. |
| **Sub-broker** | An independent agent who works for the MFD for a share of commission. |
| **Branch manager** | The person who runs a branch and its RMs. |
| **Ops / Service desk** | Back-office staff who process paperwork such as KYC, nominations and mandates. |
| **AUM** | Assets Under Management: the total value of a client's investments made through the firm. |
| **SIP** | Systematic Investment Plan: a fixed amount invested every month. "SIP book" is the total of all SIPs. |
| **SIP bounce** | A monthly SIP debit that failed (for example, not enough money in the bank). |
| **Lumpsum** | A one-time investment. |
| **Trail commission** | The ongoing commission an MFD earns every month on money that stays invested. |
| **KYC** | Know Your Customer: identity checks that every investor must complete. |
| **Nomination** | Naming who receives the investment if the investor dies. |
| **Mandate / NACH / e-mandate** | The bank permission that lets SIP money be debited automatically. |
| **RTA** | Registrar and Transfer Agent (CAMS, KFintech): the companies that process MF transactions for AMCs. |
| **AMC** | Asset Management Company: the company that runs mutual fund schemes. |
| **ARN / EUIN** | The registration numbers an MFD firm (ARN) and each of its employees (EUIN) need from AMFI to sell mutual funds. |
| **AMFI** | Association of Mutual Funds in India: the industry body. Its rules forbid sales contests and allow MFDs only "incidental advice". |
| **BSE StAR MF / NSE** | Exchange platforms where MFDs place mutual fund transactions. |
| **Family head** | The main person of a client family. Investments are often viewed family-wise. |
| **Tier A / B / C** | Client groups by importance (usually AUM). Tier A gets the most frequent reviews. |
| **Portfolio review** | A periodic meeting to go through a client's investments. |

## CRM terms
| Term | Meaning |
|---|---|
| **CRM** | Customer Relationship Management: software to track clients, prospects, tasks and every interaction. |
| **Lead** | A prospect: someone who might become a client. |
| **Opportunity** | A chance to do more business with an existing client (SIP top-up, FD maturity, insurance renewal). |
| **Pipeline** | All open leads or opportunities, grouped by how far along they are. |
| **Stage** | A step in the pipeline (New → Contacted → Follow-up → Hot → Won/Lost). |
| **Kanban** | A board of cards in columns, one column per stage. You move a card when its stage changes. |
| **Follow-up** | The next agreed contact with a lead or client, with a date. |
| **Collaborator** | A colleague added to a record so they can see and help with it. |
| **Activity** | Anything a person did: a call, visit, meeting, WhatsApp, email or completed task. |
| **Timeline / Comments & Activities** | The running history on a record of everything that happened, in date order. |
| **Service request (SR) / Case** | A client asks for something to be done (change bank, add nominee). It gets a reference number and a deadline. |
| **SLA** | Service Level Agreement: the promised time to finish a request (for example, 5 business days). |
| **SLA pause** | The clock stops while we wait on someone else (the RTA, the bank, the client), so staff are not blamed for others' delays. |
| **Escalation** | The request is automatically flagged to a senior person when it is close to, or past, its deadline. |
| **Triage** | Sorting new incoming requests and assigning each one to the right person. |
| **Health score** | A 0–100 number showing how "at risk" a client relationship is (SIP stopped, no contact, complaints, and so on), with the reasons shown. |
| **Coverage** | Whether each client was contacted or reviewed as often as their tier promises. |
| **Auto-assignment / Round robin** | New leads are shared out automatically, one by one, across RMs. |
| **Automation** | A rule: "When X happens, if Y, then do Z" (e.g. when an SIP bounces, create a task for the RM). |
| **Saved view** | A filter you saved so you can open it again in one click ("My overdue tasks"). |
| **Bulk action** | Doing the same thing to many selected rows at once (reassign, mark done). |
| **Drawer / side panel** | A panel that slides in from the right for a form or details, keeping the list visible behind it. |
| **Command palette (Ctrl+K)** | A search box that finds any client, lead or action from anywhere. |
| **MIS** | Management Information System: reports and numbers for managers and owners. |
| **KPI** | Key Performance Indicator: an important number to track (e.g. % follow-ups done on time). |

## AI and technology terms
| Term | Meaning |
|---|---|
| **AI-identified / AI score** | The system spots a likely opportunity and scores it 0–100 for how promising it is. A person must accept it before it counts. |
| **AI draft** | Text the AI writes (a meeting summary, a WhatsApp reply) that a person checks and approves before use. |
| **"Internal — not advice"** | A label on AI and research insights. They are for staff only and are never sent to clients as advice. |
| **WhatsApp Business API** | The official way for a business to use one WhatsApp number across a team, with templates and an audit trail. |
| **24-hour window** | WhatsApp rule: you can reply freely for 24 hours after the client's last message. After that, only pre-approved template messages can be sent. |
| **Template (WhatsApp)** | A pre-approved message format (e.g. birthday wishes, SIP reminder) that Meta has cleared. |
| **SaaS** | Software as a Service: one product online, used by many firms, each with its own private data. |
| **Sync** | Copying the latest data from MF Box into the CRM automatically. |
| **SSO / 2FA** | Single sign-on (one login for MF Box and the CRM) / two-factor authentication (a code on your phone as well as the password). |
| **Watermark** | Text stamped on a downloaded file (who downloaded it and when), to discourage leaks. |
| **Masking** | Hiding part of a number (ABCPV••••K) so only the needed part is visible. |
| **Light / dark theme** | Two colour modes for the app; dark is easier on the eyes at night. |
| **Wireframe / mock-up** | A clickable picture of the product used to agree the design before building it. Nothing is saved. |
